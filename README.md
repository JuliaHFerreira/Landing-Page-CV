# Portfólio de Júlia Helena Ferreira

Landing page de currículo e portfólio de desenvolvimento backend Java. A página reúne trajetória profissional, competências, projetos, formação e canais de contato.

## Executar localmente

Abra [index.html](index.html) em um navegador moderno. O site usa HTML, CSS e JavaScript nativos e pode ser servido por qualquer hospedagem estática com a estrutura de arquivos do repositório. As fontes do Google dependem de rede e têm fontes alternativas no CSS.

## Trabalhar com o BMAD

Abra o repositório no Codex e invoque a skill pelo nome, como `$bmad-help`. Use [o guia do projeto](docs/guia-de-trabalho.md) para escolher o fluxo e localizar os artefatos.
